
# ZBY 编程语言

**ZBY（ZBY Programming Language）** 是一门面向编程初学者与 AI 编程 Agent 协作开发的轻量级解释型通用脚本语言。

本项目旨在通过简洁统一的语法、明确可预测的执行规则以及清晰的错误诊断机制，降低程序理解、编写和调试的成本。

## 核心设计理念

- **简洁性（Simplicity）**：精简语言规则，统一语法结构，让程序容易学习、阅读和编写。
- **明确性（Explicitness）**：强调显式声明和明确的语义规则，使程序行为更加可预测。
- **可解释性（Explainability）**：提供清晰的错误信息和诊断机制，帮助开发者理解和解决问题。

## 项目目标

1. 设计一套具有自身规范的解释型脚本语言。
2. 开发能够完整执行 ZBY 程序的解释器。
3. 建立覆盖语言功能的自动化测试集。
4. 完成与 Python 的性能对比测试。
5. 编写面向人类开发者和 AI Agent 的开发指南。
6. 使用 ZBY 开发一个具有实际功能的应用程序。

## 项目结构

- `docs/`：项目介绍、语言规范和开发文档
- `src/`：解释器源代码
- `tests/`：自动化测试
- `examples/`：语言示例程序
- `benchmarks/`：性能测试
- `app/`：使用 ZBY 开发的应用程序
- `reports/`：测试与性能报告
- `presentation/`：项目介绍与演示材料
