# ZBY 语言规范（V0.2 初稿）

> 状态：**规范初稿，待审查**。设计方案已认可不等于解释器已实现或测试已通过。
> 关联：`design-decisions.md`、`type-system.md`、`grammar.ebnf`、`open-questions.md`。
> 规范依据：截至 DD-078 的已认可设计方向。
> 版本目标：V0.2 规范基线；正式发布版本尚未确定。

## 1. 范围与运行模型

ZBY 是采用 UTF-8 `.zby` 源文件的解释型脚本语言。程序可以直接包含顶层语句，不需要 `main()`。V1.0 的类型包括 `int`、`float`、`string`、`bool`、一维同质数组和 `struct`；`void` 只允许作函数返回类型。

执行一个源文件时，解释器先完成整个文件的词法分析、语法分析及必要的结构上下文检查；如果出现词法/语法/非法 `return`、`break`、`continue`，则不得执行任何顶层语句。执行阶段按顶层语句顺序运行，并逐条注册函数、结构体。函数体在调用时执行。运行时发生第一个实际错误后终止，不撤销已经完成的输出或复合对象修改。

> 例外说明：运行前的结构上下文检查不是完整静态类型检查；名称和类型等错误可能只有执行到相关路径才出现。规则来源 DD-011、DD-038、DD-044、DD-067、DD-077。

## 2. 词法

### 2.1 编码、注释和空白

- 源文件编码为 UTF-8；仅文件开头允许 UTF-8 BOM。
- 合法空白：空格、水平制表符、LF、CRLF；空白通常只分隔 Token。
- `//` 开始单行注释，到本行末尾结束；不支持 `/* ... */`。
- 字符串里的 `//` 只是普通字符。
- 行号和列号均从1开始，列号按 Unicode 码点计数，Tab 占一个码点。输出定位标记的视觉对齐规则待确认。
- 空源文件、空 `{}` 块合法；独立分号 `;` 不合法。

### 2.2 标识符、关键字和内置名称

标识符匹配 `[A-Za-z_][A-Za-z0-9_]*`，大小写敏感。中文与其他 Unicode 字符可以出现在字符串或注释中，但不能出现在标识符中。

保留字及类型名（20个）：

`let fn return struct if else while for break continue true false and or not int float string bool void`

预留内置函数名（10个）：

`print input len push pop clone to_int to_float to_string int_div`

内置函数名不是普通变量或用户函数可覆盖的名称；结构体字段名称的冲突细则仍列为待决项 S07。

### 2.3 数字字面量

- 整数：`0` 或不以零开头的十进制数字串。
- 浮点：合法整数部分加 `.` 与至少一位小数，或合法整数部分/小数形式加 `e/E` 指数。
- 例：`42`、`0.5`、`1e3`、`2.5E-4` 合法；`012`、`.5`、`1.`、`1e` 非法。
- 源代码中的 `-42` 解析为一元 `-` 与 `42`；除指数符号外，正负号不属于字面量 Token。源码不支持一元 `+`，但 `to_int("+42")` 合法。
- 数字词法合法与数值范围可表示性是两个不同问题：`1e309` 的数字格式合法，但无法得到有限 binary64 值，按浮点溢出处理。

### 2.4 字符串字面量

只支持双引号字符串。允许直接出现 Unicode 文本，但不能直接跨源码行；支持 `\n`、`\t`、`\r`、`\"`、`\\`。未知转义、未闭合引号或反斜杠触及字符串结尾均报词法错误。字符串不可变，不支持切片；下标只读且返回一个 Unicode 码点对应的 `string`。

## 3. 变量和类型

声明统一为 `let name: Type = Expression;`；类型不可省略，初始值必须提供。变量可以重新赋值，但绑定类型保持不变；无隐式 `int`→`float`、`bool`→`int` 或字符串转换。

```zby
let age: int = 20;
let name: string = "ZBY";
age = age + 1;
```

`let age = 20;` 非法。`age = "twenty";` 在执行时发生类型错误。`void` 不能用于变量、数组元素或结构体字段。

数组、结构体采用共享引用：变量赋值/函数传参/返回时不隐式复制对象；`clone()` 明确创建深拷贝并保留副本内部原有别名关系。基本类型按值使用。完整类型矩阵见 `type-system.md`。

## 4. 表达式

### 4.1 运算符

支持 `+ - * / %`、`< <= > >=`、`== !=`、`and or not`、一元负号、函数调用 `()`、下标 `[]`、字段访问 `.` 与分组括号。

从高到低为：后缀操作；一元负号；`* / %`；`+ -`；关系比较；相等比较；`not`；`and`；`or`。算术及 `and/or` 左结合、一元运算右结合。无括号连续比较无效，例如 `a < b < c`、`a < b == true`；必要时使用括号或逻辑运算。

先按语法形成表达式树，再从左到右求值树中的操作数；对 `and` 和 `or` 应用短路规则。`false and RHS` 与 `true or RHS` 不计算 RHS；执行到的逻辑操作数必须为 `bool`。跳过 RHS 并不跳过全文件词法/语法检查。

### 4.2 数值和比较语义

- `int` 是任意精度带符号整数，受实际内存/运行资源限制。
- `float` 为有限 IEEE 754 binary64，允许 `-0.0` 与下溢到零；除零和运算溢出时报错，不提供 NaN/Infinity 字面量。
- `int/int` 的普通 `/` 得到 `float`：数学精确商按 binary64 最近值舍入（中点取偶）；不能先将超大整数操作数各自转成 float 再运算。
- `int_div(int,int)` 向负无穷取整；`%` 与除数同号（或为零），满足商余恒等式。
- `+` 允许 `string + string`；不支持跨类型隐式转换。数组和结构体不直接支持 `==/!=`。

详细类型约束与函数转换签名见 `type-system.md`。

## 5. 赋值与复合目标

赋值是语句，不是表达式；不允许 `a = b = 5;`、`if (x = 1) {}`，V1.0 暂不支持 `++`、`--`、`+=`、`-=`（保留后续扩展意向）。

赋值目标必须以变量名起始，可接任意合法的 `.field` 或 `[index]` 访问链，例如 `x`、`numbers[0]`、`students[0].scores[1]`。不能直接向 `make_student().age` 赋值。字符串下标不可赋值。

执行赋值时先解析并定位左侧对象/下标/字段，完成可在右侧求值前确定的检查，然后求右侧表达式并重新验证目标有效性与目标类型，最后写入。右侧重绑定变量不应改变已经定位的复合对象；右侧副作用导致目标位置无效时报错。具体失败类别仍待实现测试确认。

## 6. 数组

数组采用 `T[]` 类型表示一维同质数组；`T` 为基本类型或已注册的非递归结构体类型，不支持数组嵌套类型 `T[][]`。

```zby
let scores: int[] = [90, 95];
let empty: int[] = [];
push(scores, 100);
let last: int = pop(scores);
print(len(scores));
```

非空数组所有元素必须兼容同一类型，无隐式转换。空数组 `[]` 需要由变量声明、函数参数、函数返回类型或结构体字段等明确预期数组类型确定；无此上下文的 `print([])` 不合法。

数组下标从0开始，必须为非负 `int`，越界报错。`pop` 空数组报错；`push` 修改原对象；`pop` 移除并返回最后元素，复合元素按共享引用返回；`len` 返回元素个数。

## 7. 结构体

结构体采用显式字段声明，字段都必须有类型。创建时使用命名字段构造，每个声明字段必须恰好初始化一次；字段顺序不决定语义。允许非递归结构体嵌套和结构体数组；禁止直接与间接的结构体递归类型依赖。

```zby
struct Student {
    name: string;
    scores: int[];
}
let s: Student = Student { name: "Alice", scores: [90, 95] };
let students: Student[] = [s];
```

结构体字段中的其他结构体类型、函数形参/返回值中的结构体类型均要求在对应定义注册时已经存在。结构体的字段可以修改但必须保持声明类型。默认字段值、类继承与动态增删字段不属于 V1.0。

## 8. 函数与作用域

函数定义 `fn name(params) -> ReturnType { ... }`；不支持函数嵌套定义、默认参数和闭包。`void` 函数可以执行到末尾或用 `return;` 提前返回；非 `void` 函数必须在实际执行路径返回声明类型，否则执行至末尾时报运行时错误。

作用域为词法作用域，内层普通变量可遮蔽外层普通变量；同一作用域禁止重复声明。形参可遮蔽全局普通变量，但不得与同层局部变量、其他参数或函数/结构体/内置名称冲突。函数可以读取和修改已经存在的全局变量。

函数定义执行到时注册，不执行函数体；只有实际调用前已注册的函数才能被调用。函数体中的普通名称在执行到时解析，因此允许两个函数都注册之后的相互递归。类型名称在函数签名注册时解析。

函数调用先检查实参数量；数量正确才按源码顺序逐个求值并立即检查对应类型。遇错误不执行剩余参数；全部通过后才进入函数体/执行内置操作。独立函数调用可作为语句，返回值可以丢弃；普通算术表达式不允许独立作为语句。递归深度上限可配置，默认值尚待最终确认。

## 9. 控制流

`if/else if/else` 必须有花括号；从上到下评估条件，只执行首个为真的分支，执行块具有局部作用域。`while (condition) { ... }` 每轮先检查 bool 条件，每轮创建新的代码块作用域。

`for (let i: int = 0; i < limit; i = i + 1) { ... }` 要求初始化、条件和更新三段均存在。初始化执行一次，之后循环执行条件检查→循环体→更新→条件检查。初始化变量只在循环内可见，每轮循环体具有独立局部作用域。

`break;` 退出最近一层循环；`continue;` 跳过当前轮剩余语句：在 `for` 中仍执行更新后判断条件，在 `while` 中直接重新判断。`return;`、`break;`、`continue;` 出现在不合法的静态上下文时，在执行前拒绝整个程序。

## 10. 内置函数及输入输出

| 名称 | 签名和主要行为 |
|---|---|
| `print` | `print(value, ...) -> void`；零个或多个值，以空格分隔，末尾 LF；支持复合类型 |
| `input` | `input() -> string` 或 `input(prompt: string) -> string`；一行文本，EOF 报输入错误；提示在 stdout 上不自动换行 |
| `len` | `len(T[]) -> int`；`len(string) -> int`，字符串按 Unicode 码点计数 |
| `push` | `push(T[], T) -> void`，就地追加元素 |
| `pop` | `pop(T[]) -> T`，移除并返回最后一个元素；空数组报错 |
| `clone` | `clone(T[]|struct) -> 原复合类型`，深拷贝可变子对象、保留副本内部别名 |
| `int_div` | `int_div(int,int) -> int`，向负无穷取整 |
| `to_int` | 显式转换为 int；支持 int/float/严格整数字符串等 DD-022 允许的输入 |
| `to_float` | 显式转换为有限 float；支持 int/float/严格数字字符串等 DD-022、DD-073 输入 |
| `to_string` | 显式转换为 string；支持基本类型，不直接转换复合类型 |

对顶层字符串直接打印内容；数组为 `[a, b]` 形式；结构体为 `TypeName { field: value }` 形式，成员字符串带引号及必要转义，字段按声明顺序输出。`float` 使用最短可回读 binary64 文本，`1.0` 和 `-0.0` 保留浮点特征。`print` 输出采用 UTF-8、LF；运行时诊断写 stderr。

## 11. 错误与退出行为

错误分类包括 `LexError`、`SyntaxError`、`NameError`、`TypeError`、`IndexError`、`ZeroDivisionError`、`ValueError`、`ArgumentError`、`InputError`、`ResourceError`。诊断统一提供 ZBY 源文件名、1基行/列位置、错误类别及明确原因；可获得时补充源码标记、期望/实际类型、简化的 ZBY 函数调用栈和有根据的修复提示。

词法/语法及结构性错误：执行前报首错，不执行任何顶层语句。运行时错误：立即终止、不回滚已完成副作用。正常结束退出码0；错误、文件不存在和调用方式错误退出码1。程序文本写 stdout，诊断写 stderr。V1.0 不提供 `try/catch`。
