# ZBY V0.2 语言规范待决事项清单

> 本文是设计工作清单，不是已定稿的语言规范。
>
> 状态：已认可（待实现及验证） / 候选（未认可） / 暂定 / 未规定 / 历史冲突已消解。优先级：P0（阻塞实现）、P1（V0.2 发布前需要确定）、P2（可推迟或明确不支持）。

## 0. 已有草案冲突

| 编号 | 问题 | 状态 |
|---|---|---|

## 处理顺序

1. 数值、字符串、转换与运算边界。
2. 数组、结构体及引用语义。
3. 名称、作用域、函数调用和返回。
4. 表达式、运算符、求值顺序。
5. 控制流与异常行为。
6. 完整 EBNF 与实例的一致性校验。
7. 用户文档、AI 文档与黑盒测试设计。

每项正式定稿必须同步修改设计决策记录和正式语言规范，并给出至少一条边界测试。禁止把暂定方案描述为已实现。V0.2 全部审查后再打 v0.2.0 标签。

## 一致性检查与仍需完成的项目

1. **已消解的历史冲突**：X01～X05 已有后续决策；DD-013→DD-029、DD-014→DD-024～DD-026、DD-033→DD-038、DD-037→DD-040/041 已同步标明；旧论证保留为设计历史。
2. **语法与词法 P0**：L01 完整关键字及内置名，L02 标识符字符集，L05 数值字面量，L08 空块/空语句，赋值目标及运算符的 EBNF。
3. **数值 P0**：T02～T04 的 `float` 非有限值及任意精度整数除法边界，T10 各显式转换的输入文法。
4. **复合类型 P0/P1**：D05 空数组类型及数组字面量类型；D06 数组内置操作；D04/D10 结构体数组及定义先后；D09 深拷贝异常边界。
5. **控制与运行 P0/P1**：`while` 完整语法、非法 `return/break/continue` 的诊断阶段、`input`/`print` 规范、R01/R02/R04/R05/R08 的错误协议及资源限制。
6. **扩展观察项**：实际应用若大量出现计数和累加，优先重新评估 `+=`、`-=`、`++`、`--`（DD-048），而非永久排除。

当前所有示例均属于规范预期行为和待执行测试，不表示解释器已有实现或测试通过。正式 EBNF、语言规范和一致性测试完成后才可发布 `v0.2.0`。

### 不一致与潜在歧义的处理

1. **旧条款与后续决策**：DD-018 的“暂不新增整数除法运算符”并不妨碍 DD-049 的 `int_div` 内置函数；保留历史记录并注释最新范围。DD-020 的码点长度不自动等于 `len` 的所有签名已定稿。
2. **表示形式的差异**：严格的源码数字字面量（DD-052）与字符串数值转换（DD-051）是两个入口；例如 `"+42"` 可转换，但源码一元正号未加入 DD-045，需要在语言规范显式解释。
3. **结构检查与运行时类型检查**：DD-067 的执行前静态检查仅针对语法与控制结构上下文，不代表已引入完整静态类型分析器，保留 DD-011。
4. **已预留内置名≠功能签名已定稿**：DD-054 的 `push/pop/len/print/input` 等名称不可占用，但其候选参数类型、返回与异常仍在 DD-058～DD-065 中。
5. **深拷贝语义与候选别名细节**：DD-025 已确定深拷贝，候选 DD-062 是其内部别名映射及失败处理的进一步细化，不得当作已确认。
6. **条件和比较表达式**：优先级（DD-046）先定义语法树，DD-042 再规定树内求值顺序；短路是有条件地跳过右操作数。
7. **错误输出**：DD-066/068/069 已确认诊断内容和通道，具体源码片段对齐、错误码、调用栈截断、输出编码仍未冻结。
8. **递归限制**：DD-071 已认可可配置上限，默认256层仍仅是待验证建议值。

## 复合类型及函数调用方案正式确认（2026-11-27）

- DD-058：一维同质数组与上下文确定空数组类型；上下文包括变量声明、函数实参、函数返回与结构体字段。
- DD-059：非负 `int` 下标、从零开始；字符串索引返回单个 Unicode 码点组成的 `string`，不可修改。
- DD-060：`push(array, value)` 修改数组并返回 `void`，`pop(array)` 移除并返回末项（复合项保持共享引用），`len(array|string)` 返回 `int`。
- DD-061：结构体字段必须完整命名初始化，支持结构体数组，结构体类型先定义后使用，禁止递归结构体类型依赖。
- DD-062：`clone` 深拷贝维护副本内部别名关系，并与源的可变子对象隔离。
- DD-063：`print` 支持零或多个基本及复合类型实参，空格分隔、末尾换行，具体字节级数值与复合格式仍待规范。
- DD-064：`input` 可选字符串提示；返回行文本，保留普通空白，空行返回空串，EOF 报错，具体刷新/编码待规范。
- DD-065：**统一修订规则**，用户函数和内置函数均先验证实参数量，再自左向右逐项求值并立即检查对应参数类型，首错停止其余实参，全部合法后进入函数体或执行内置操作。
