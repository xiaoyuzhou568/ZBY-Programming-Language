# ZBY V0.2 语言规范待决事项清单

> 状态：已确定 / 暂定 / 未规定 / 冲突。优先级：P0（阻塞实现）、P1（V0.2 发布前需要确定）、P2（可推迟或明确不支持）。

## 0. 已有草案冲突

| 编号 | 问题 | 状态 |
|---|---|---|
| X01 | 完整静态检查与严格运行时检查曾分别被建议 | 冲突；当前偏向运行时检查 |
| X02 | int 到 float 自动转换与全部显式转换之间的矛盾 | 冲突；当前偏向显式转换 |

2. 数组、结构体及引用语义。

5. 控制流与异常行为。
6. 完整 EBNF 与实例的一致性校验。
7. 用户文档、AI 文档与黑盒测试设计。
