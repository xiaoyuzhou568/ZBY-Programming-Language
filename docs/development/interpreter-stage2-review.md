# ZBY Interpreter 第二阶段实现与验证记录

## 1. 范围和基线

本阶段基于上一版182项测试通过的执行原型，扩展已有 Interpreter，不引入新的 Lexer、Parser 或 AST 节点类型。保留前一阶段源代码，并将唯一一项旧式“复合类型不支持”的测试更新为实际行为回归。

本轮测试共276项，其中新增94项复合类型回归测试。测试结果以压缩包实际复验为准。

## 2. 实现决策与关键不变量

| 主题 | 实现规则 | 关键不变量 |
|---|---|---|
| 数组值 | `ZbyArray(element_type, elements)` | 只能有一个静态确定的元素类型；不支持 `T[][]` |
| 结构体值 | `ZbyStruct(type_name, fields)` | 类型名确定字段类型与声明顺序；每个字段初始化一次 |
| 类型检查 | 精确 `T` / `T[]` 类型名匹配 | `int` 与 `float` 不隐式转换；`bool` 与 `int` 严格区分 |
| 空数组 | 上下文预期 `T[]` 才允许空值 | 裸 `[]` 不自动变成 `any[]` |
| 引用共享 | 变量、参数、返回值携带同一对象引用 | 局部重绑定不改写其他变量绑定 |
| `push` | 追加到原数组，返回 `void` | 元素类型必须匹配；第1参数错误后跳过第2参数 |
| `pop` | 删除并返回原末尾元素 | 若是结构体，返回共享对象而非复制 |
| `len` | 字符串按 Unicode 码点，数组按元素个数 | 不接受其他类型 |
| `clone` | 使用备忘表递归复制可变复合对象 | 原对象的同一可变子对象在副本中映射为同一个新对象 |
| 左侧赋值 | 定位 LHS、检查可判定错误、求 RHS、校验并写入 | RHS 重新绑定某变量，不更改已定位的旧对象；若下标失效则报错 |
| 结构体初始化 | 先检查字段集合，再按源码书写顺序求初始化值 | 保存字段顺序与结构体声明顺序一致 |
| 参数求值 | 先检查数量，再逐项求值和校验类型 | 第 i 个参数错误时，第 i+1 个参数不执行 |
| 打印 | 格式化数组和结构体；嵌套字符串带引号和转义 | 字段顺序固定；字符串顶层原样输出 |

## 3. 代表性成功测试

1. `let a:int[]=[]; push(a,3); print(a);` 输出 `[3]`。
2. `let a:int[]=[1]; let b:int[]=a; b[0]=9; print(a[0]);` 输出 `9`。
3. `struct S{x:int;} let s:S=S{x:1}; print(s);` 输出 `S { x: 1 }`。
4. 结构体数组 `S[]` 的下标字段赋值与返回值支持。
5. `clone()` 的副本修改与原对象隔离；同时保留副本内部共享别名。
6. 空数组在函数参数、返回类型及结构体字段类型上下文中可被确定。
7. `print(["a", "b\\nc"])` 的嵌套字符串引号和换行转义稳定。

## 4. 代表性错误及副作用测试

1. 数组下标负数/越界：`IndexError`。
2. `push(int_array, "wrong")`：`TypeError`，数组不追加元素。
3. `pop(empty_array)`：`ValueError`。
4. `clone(1)`：`TypeError`，不做隐式装箱。
5. `a[9] = side_effect()`：LHS 越界，右侧函数不执行。
6. `a[0] = pop(a)`：RHS 使原下标失效，复核后报告 `IndexError`；已发生的删除不回滚。
7. 用户函数的第一个参数类型错误时，后续参数的副作用不执行；数量错误时任何实参都不执行。
8. 定义前结构体字段类型/函数签名中的结构体类型：`NameError`。
9. `struct Empty {}` 或尾随逗号仍按默认 ParserOptions 拒绝，不算语言设计已经做出最终选择。

## 5. 未封闭边界

- 精确打印规范仍需规定所有控制字符、非正常宿主资源错误和浮点非常规表达形式。
- 资源异常：本阶段仅对复合输出和 `clone` 的典型 Python 资源异常转为 `ResourceError`；极端内存消耗与主循环中断策略尚未完整实现。
- 对于共享可变复合对象，`print` 实参在整个调用的实参求值阶段可能被之后的实参修改，打印反映最终对象内容；需作为规范级金标准记录。
- 此原型没有完整静态语义检查器：类型与名称错误仍主要按实际执行路径触发；词法、语法及非法控制上下文提前检查。
- 本阶段没有进行性能基准或跨平台打包检查；仅验证 Python 标准库执行流程和 CLI 基本行为。
