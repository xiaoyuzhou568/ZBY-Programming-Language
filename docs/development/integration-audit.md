## 2. 本轮规范偏差修复

### DD-072：任意精度整数普通除法

旧实现对 `int / int` 直接调用 Python `/`，当操作数非常大时可能在计算浮点商之前溢出，例如 `10**400 / 10**400`，尽管数学商为1。

采用 Python 标准库 `fractions.Fraction` 构造精确有理商，再转换为有限 binary64 float。保留原有除零检测及非有限值失败机制。这一改动不引入 ZBY 的有理数类型，也不改变 `int_div()` 的精确整数语义。

新增测试：有限巨大商、巨大整数溢出、下溢、负零、中点向偶舍入、通常分数商。实际舍入正确性依赖 Python 运行时的 Fraction 转换；跨版本极端数值需进一步金标准验证。

## 3. 设计与实现保持分离

- 当前 Parser 默认拒绝空结构体与尾随逗号，这只是保守的实现策略；正式规范尚未确认。
- 已认可 `int_div` 为内置函数，保留 `//` 为单行注释，不引入新的整除运算符。
- 不发布 `v0.2.0` 标签；合并代码也不等于语言规范冻结。
