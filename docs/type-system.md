# ZBY 类型系统规范（V0.2 初稿）

> 状态：规范初稿，待一致性审查与测试。
> 关联：`language-spec.md`、`grammar.ebnf`、`design-decisions.md`。

## 1. 类型层级

```text
Type
├── int                 任意精度有符号整数
├── float               有限 IEEE 754 binary64
├── string              不可变 Unicode 字符串
├── bool                仅 true/false
├── Array<T>            一维同质可变数组，书写为 T[]
└── Struct<Name>        用户定义可变结构体

ReturnType = Type | void
```

`void` 不能作为数组元素、变量、形参或结构体字段的类型；只用作函数返回类型。不支持隐式类型转换，不支持 `any`、`null`、指针或多维数组。

## 2. 声明、赋值和传参

- 变量与函数形参具有显式类型。变量声明必须初始化。
- 重新赋值必须保持原绑定类型。
- 数组和结构体按共享引用传递、赋值和返回；基本值直接作为值使用。
- 函数形参的新绑定不影响调用者绑定，修改共享复合对象则可影响调用者。
- `clone` 复制全部可变子对象，不再与源共享可变数据，并保留副本对象图的别名对应关系。
- 参数调用顺序：先校验数量，再从左到右逐项求值和检查类型；任何实参不合法便停止继续求值实参。

## 3. 运算符类型规则

| 运算 | 左类型 | 右类型 | 结果 | 条件 |
|---|---|---|---|---|
| `+` | int | int | int | 精确任意精度 |
| `-` | int | int | int | 精确任意精度 |
| `*` | int | int | int | 精确任意精度 |
| `+` | float | float | float | 有限 binary64 |
| `-` | float | float | float | 有限 binary64 |
| `*` | float | float | float | 有限 binary64 |
| `/` | int | int | float | 精确商舍入 binary64，除零/溢出报错 |
| `/` | float | float | float | 除零/溢出报错，舍入遵循 binary64 |
| `%` | int | int | int | 除数非零，余数与除数同号或为零 |
| `+` | string | string | string | 拼接 |
| `< <= > >=` | int | int | bool | 数值大小比较 |
| `< <= > >=` | float | float | bool | 有限浮点比较 |
| `== !=` | int | int | bool | 精确整数比较 |
| `== !=` | float | float | bool | -0.0 与 +0.0 相等 |
| `== !=` | string | string | bool | Unicode 内容比较 |
| `== !=` | bool | bool | bool | 严格布尔比较 |
| `and or` | bool | bool | bool | 从左向右短路，未执行 RHS 不做运行时检查 |
| `not` | bool | — | bool | 一元逻辑否定 |
| 一元 `-` | int / float | — | 对应数值类型 | 无一元 `+` |

`int + float`、`int == float`、`bool + int`、`float % float` 均非法。数组和结构体不支持直接相等性比较；字符串不支持 `< > <= >=`。

> 注意：该矩阵是当前已认可的核心组合。运行期异常（资源不足、除零、非有限结果）仍可能中断合法类型组合。

## 4. 除法与余数

普通除法 `int / int` 得 `float`。整数商转换采用数学上的精确比值，再按 binary64 最近值舍入；中点取偶。运算结果必须是有限浮点值，允许下溢到带符号零。`int_div(a,b)` 使用向负无穷取整；`a % b` 与其满足：

`a = int_div(a,b) * b + (a % b)`，其中 `b != 0`。

实例：`int_div(-7,3) == -3`、`-7 % 3 == 2`。

## 5. 字符串与转换

字符串不可变，`len` 按 Unicode 码点计数，字符串下标返回单码点对应的 `string`。无字符专有类型。转换函数遵循：

| 来源 | `to_int` | `to_float` | `to_string` |
|---|---|---|---|
| int | 原值 | 转 binary64，超范围错误 | 十进制字符串 |
| float | 向零截断为 int | 原值 | 浮点规范文本 |
| string | 严格整数文法 | 严格整数或浮点数字文法 | 原值 |
| bool | 不支持 | 不支持 | `"true"` / `"false"` |
| array/struct | 不支持 | 不支持 | 不支持 |

- `to_int("+42")` 合法，`to_int("042")`、`to_int(" 42 ")`、`to_int("3.5")` 非法。
- `to_float("3")`、`to_float("+3")`、`to_float("-0")`、`to_float("1e3")` 合法。
- 数字格式合法但范围不适用的转换属于数值范围错误，而不是格式错误。
- `to_int(float)` 对有限值向零截断；零的符号在 `int` 中不保留。
- 字符串数字转换不隐式剔除前后空白；是否提供 `trim()` 是后续扩展议题。

## 6. 数组类型与空字面量

`T[]` 表示一维同质数组，`T` 可以是四种基本类型或者已注册的非递归结构体类型；`T[][]` 不支持。

非空数组字面量的元素值必须全部与上下文或已确定的元素类型匹配。空字面量 `[]` 没有独立元素类型，只能由明确的预期数组类型决定。例如：

```zby
let x: int[] = [];

fn create() -> int[] {
    return [];
}
```

函数形参和结构体字段也可提供预期类型。`print([])` 缺少数组类型信息，应被拒绝。

数组元素下标是非负 `int`，首个元素下标为0，越界报 `IndexError`。数组可以就地修改、`push` 和 `pop`；`pop` 对结构体元素返回同一复合对象的引用，不做隐式复制。

## 7. 结构体类型

结构体字段须具有显式、非 `void` 类型，构造时每个字段恰好出现一次；不提供默认字段值。命名字段的求值按源码书写顺序进行。结构体字段的结构体类型及函数签名中的结构体类型必须先于定义注册。禁止直接/间接递归结构体类型依赖，包括经数组的回路。

结构体字段值可以是数组或另一非递归结构体；结构体数组一维且元素类型相同。结构体中的可变子对象可与其他字段共享；深拷贝必须保留副本内部的对应别名关系。

## 8. 内置函数签名

| 名称 | 类型约束 | 结果类型 | 副作用 |
|---|---|---|---|
| `print` | 任意数量可打印值 | void | 写 stdout |
| `input` | 0个参数或1个 string 提示 | string | 写提示、读 stdin |
| `len` | `T[]` 或 `string` | int | 无 |
| `push` | `T[]`, `T` | void | 修改共享数组 |
| `pop` | `T[]` | T | 移除末尾元素 |
| `clone` | `T[]` 或结构体 | 同一复合类型 | 创建独立对象 |
| `int_div` | int,int | int | 无 |
| `to_int` | int/float/string | int | 无 |
| `to_float` | int/float/string | float | 无 |
| `to_string` | int/float/string/bool | string | 无 |

其中 `T` 代表调用时确定的具体元素类型，并不是 ZBY V1.0 支持用户自定义泛型语法。

## 9. 错误检测阶段

- 执行前：词法错误、语法错误以及非法上下文的 `return`、`break`、`continue`。
- 注册期：结构体和函数签名中未注册的类型名、重复声明与名称冲突（具体错误类别待统一）。
- 执行期：操作数类型、名称解析、数组下标、函数实参数量/类型、未返回规定类型、除零及资源限制。
- 无完整静态类型检查器，因此短路未执行部分的运行时类型错误不触发；不过其源码仍必须能通过词法语法分析。

## 10. 尚待补齐的精确规范

1. 非标准控制字符的复合输出转义；浮点指数格式标准化规则。
2. 空结构体、尾随逗号和复杂函数调用语法的最终处理。
3. AST 中每个类型上下文传播位置，特别是空数组和 `void` 返回值。
4. 运行期与注册期错误的精确分类、错误码及显示细节。
5. float 极端数值舍入及下溢的黑盒黄金用例。
