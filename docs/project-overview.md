
# ZBY 项目介绍

## 1. 项目概述

ZBY 是一门面向编程初学者与 AI 编程 Agent 协作开发的轻量级解释型通用脚本语言。

项目不仅关注语言本身的语法设计，也关注解释器的实现、程序的可靠性以及开发者的使用体验。

## 2. 项目背景与动机

现有编程语言具有丰富的功能和成熟的生态，但复杂的语法规则和语言机制可能增加初学者的学习成本，也会给程序理解、调试和 AI 辅助开发带来一定困难。

ZBY 希望通过精简且统一的语法、明确的类型规则和清晰的错误诊断机制，降低程序开发过程中的理解和调试成本。

## 3. 目标用户

ZBY 主要面向两类使用者：

### 3.1 编程初学者

帮助初学者理解程序结构、数据类型、控制流程和函数调用，降低学习和使用编程语言的门槛。

### 3.2 AI 编程 Agent

通过统一的语法规则、规范化的开发文档和明确的错误反馈，使 AI Agent 能够更加准确地生成、修改和调试 ZBY 程序。

## 4. 项目目标

- 设计一套具有完整基本功能的脚本语言。
- 实现能够执行 ZBY 源代码的解释器。
- 建立覆盖语言功能的自动化测试集。
- 进行与 Python 的性能对比实验。
- 编写面向人类和 AI Agent 的开发指南。
- 使用 ZBY 完成具有一定规模的实际应用。

## 5. 核心设计方向

项目围绕以下三个理念展开：

1. 简洁性：控制语言复杂度，保持语法统一。
2. 明确性：强调显式声明和确定的执行规则。
3. 可解释性：提供清晰、可定位的错误诊断。

## 6. 技术实现计划

解释器计划使用 Python 实现，采用模块化架构。

主要包括：

- 词法分析器（Lexer）
- 语法分析器（Parser）
- 抽象语法树（AST）
- 语义分析与类型检查模块
- 解释执行器（Interpreter）

## 7. 项目开发计划

项目按照以下阶段推进：

1. 项目初始化与设计理念确立。
2. 语言基本语法和类型系统设计。
3. 词法分析与语法分析实现。
4. 解释器核心功能实现。
5. 自动化测试与错误处理。
6. 性能测试与开发文档编写。
7. AI Agent 辅助应用开发。
8. 项目验收与最终材料整理。

## 8. 版本管理

项目使用 Git 进行版本控制，并通过 GitHub 保存源代码、设计文档和开发记录。

每个重要开发阶段形成独立的版本记录，保证项目开发过程可追溯。
